# Productions

Each series or film has its own folder. Series contain a `series_bible.md` and one folder per episode. Every episode (or film) follows the same layout:

```
<episode>/
├── 01_development/      ← episode plan, characters, research, screenplay
├── 02_preproduction/    ← visual guide, casting, production config, shot lists
└── 03_production/       ← voice scripts, prompt overrides, production notes
```
