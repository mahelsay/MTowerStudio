Three layers

  • Orchestration — the orchestrator owns the board: assigns work, enforces spend/approval/phase gates, routes problems.
  • Agents — a specialist crew; each reads & writes the shared shot contract, never each other.
  • Capability — the MTower library, engine, and Azure Foundry / fal.ai models, used as tools.

Design full, deploy phased

  • Wave 1 — Orchestrator · Script · Director · Research · Image QA · Studio Critic.
  • Wave 2 — Casting · Wardrobe · Makeup & Hair · Set · Camera · Stunt / Action.
  • Wave 3 — Dialect · VFX · Continuity · Sound · Editor (+ Marketing).

QA on every step

No output is accepted until it passes the gate — Tier 1 rules → Tier 2 Studio Critic → Tier 3 Image QA. The reviewer is never the author. The studio's structural defense against drift.

Grounded in your taste

At kickoff the studio asks you for references — films, footage, photos, writings, music — and builds a cited, versioned Tone Bible every agent draws on.

Validation — three tiers, on every step

I
Rules — deterministic, free. Schema valid, library IDs resolve, required fields present, no open flags, cost within cap. Every write.
II
Studio Critic — cheap text. An independent reviewer checks every non-image decision against the agent's definition-of-done.
III
Image QA — vision. Anatomy, identity (face-match auto-fail), period, props, physics, light, tone. Gate 8/10, hero shots 9.
